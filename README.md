## Project Overview

This project analyzes agricultural performance across the Kharif, Rabi and Zaid seasons using data analytics techniques.

The analysis investigates seasonal differences in:
- Crop yield
- Production
- Environmental conditions
- Water usage and efficiency
- Resource usage
- Revenue and profit
- Disease and pest risk

## Dataset

The dataset contains 4,000 farm records and 28 variables covering agricultural, environmental, resource and economic information.

## Objectives

1. Analyze agricultural performance across seasons.
2. Identify seasonal patterns and variations.
3. Examine relationships between environmental conditions and agricultural outcomes.
4. Compare crop and resource performance across seasons.
5. Apply statistical analysis to evaluate seasonal differences.
6. Develop evidence-based recommendations.
